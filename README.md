## 🚀 Proyecto destacado

Este proyecto consiste en el desarrollo de una **API REST para la gestión y transferencia de fondos**, desarrollada como parte de una solución orientada a servicios financieros.

El objetivo fue aplicar buenas prácticas de desarrollo backend para construir una solución estructurada, segura y mantenible.

### 💡 ¿Qué desarrollé?

- 🔹 Desarrollo de una **API REST** utilizando **C# y .NET**.
- 🔹 Implementación de funcionalidades para la gestión de operaciones y transferencias.
- 🔹 Integración con **SQL Server** para la persistencia y gestión de información.
- 🔹 Implementación de autenticación y seguridad mediante **JWT**.
- 🔹 Aplicación de principios de desarrollo backend y arquitectura de servicios.
- 🔹 Desarrollo de **pruebas unitarias con xUnit** para validar la funcionalidad de la aplicación.
- 🔹 Enfoque en código mantenible, escalable y organizado.

### 🛠️ Tecnologías utilizadas

| Tecnología | Uso |
|------------|-----|
| 💻 C# | Desarrollo del backend |
| ⚙️ .NET | Framework principal |
| 🌐 REST API | Comunicación mediante servicios |
| 🗄️ SQL Server | Gestión de datos |
| 🔐 JWT | Autenticación y seguridad |
| 🧪 xUnit | Pruebas unitarias |

### 🎯 Lo que demuestra este proyecto

Este proyecto representa mi experiencia en el desarrollo de **soluciones backend orientadas al sector financiero**, aplicando tecnologías como **C#, .NET, APIs REST, SQL Server, JWT y pruebas unitarias**.
